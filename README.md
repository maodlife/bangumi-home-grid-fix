# Bangumi 首页跳看进度格子修正

用于修正 Bangumi 首页把“已看总数”误当成连续观看进度的问题。

例如仅标记了《名侦探柯南》第 518、519 话时，原首页会从 `02` 开始显示；启用脚本后会从最高已看正片 `519` 开始显示，并把下一话快捷操作修正为 `ep.520 看过`。

## 安装

1. 在浏览器中安装 Tampermonkey 或 Violentmonkey。
2. 打开 [`bangumi-home-grid-fix.user.js`](./bangumi-home-grid-fix.user.js)，将内容安装为新用户脚本。
3. 登录 `https://bgm.tv/` 并刷新首页。

脚本首版只匹配 `https://bgm.tv/` 首页。

## 使用

- 在首页条目标题旁点击 `[修正格子]`。
- 设置会按条目保存在用户脚本管理器的本地存储中。
- 此后每次加载首页，脚本都会重新读取已启用条目的章节页。
- 点击 `[恢复原始]` 会关闭该条目的修正并刷新首页。
- 读取失败时，原页面保持不变；点击 `[修正失败，重试]` 可重试。

脚本只计算编号为纯数字的正片，忽略 SP、OP、ED 等其他章节类型。它仅向同域名的 `/subject/{id}/ep` 发起读取请求，不需要 Bangumi API Token，也不会向第三方发送数据。
